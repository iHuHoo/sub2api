# Aox v0.1.165 WooshPay Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce and verify the first Aox WooshPay release on official Sub2API `v0.1.165`, reported as `v0.1.165-aox.0.0.1 (WooshPay)`, without allowing the official in-place updater to overwrite the Aox payment implementation.

**Architecture:** Create `upgrade/v0.1.165` from the immutable official tag, merge the reviewed generic WooshPay branch, and add only the Aox distribution policy on top. Keep the already verified WooshPay Hosted Checkout and webhook flow; change only its desktop launch from a popup to the current tab. Mark Aox artifacts with build type `aox`, enforce the managed-update prohibition in the backend, and render managed status rather than update controls in the frontend.

**Tech Stack:** Go 1.26, Gin, Vue 3, TypeScript, Vitest, Docker, GitHub Actions.

## Global Constraints

- Official base: exact tag `v0.1.165`.
- Display version: `v0.1.165-aox.0.0.1 (WooshPay)`.
- Git tag: `v0.1.165-aox.0.0.1`.
- Docker tag: `v0.1.165-aox.0.0.1`.
- Build type: `aox`.
- Keep WooshPay Hosted Checkout, CNY, Alipay, UnionPay, and signed webhook fulfillment.
- Do not add WooshPay SDK or Direct PaymentIntent integration in this release.
- Do not automatically deploy production.
- Aox builds must reject in-place update and rollback in the backend; UI-only hiding is insufficient.

- [ ] **Step 1: Add failing backend tests for the managed build**

Add:

```go
func TestAoxBuildDisablesManagedUpdateOperations(t *testing.T) {
    svc := NewUpdateService(cacheStub, githubStub, "0.1.165-aox.0.0.1", "aox")

    info, err := svc.CheckUpdate(context.Background(), true)
    require.NoError(t, err)
    require.Equal(t, "aox", info.BuildType)
    require.Equal(t, "0.1.165-aox.0.0.1", info.CurrentVersion)
    require.Equal(t, info.CurrentVersion, info.LatestVersion)
    require.False(t, info.HasUpdate)

    require.ErrorIs(t, svc.PerformUpdate(context.Background()), ErrAoxManagedUpdateDisabled)
    require.ErrorIs(t, svc.Rollback(), ErrAoxManagedUpdateDisabled)
    _, err = svc.ListRollbackVersions(context.Background())
    require.ErrorIs(t, err, ErrAoxManagedUpdateDisabled)
    require.ErrorIs(
        t,
        svc.RollbackToVersion(context.Background(), "0.1.164"),
        ErrAoxManagedUpdateDisabled,
    )
}
```

The stubs must record calls and assert that Aox `CheckUpdate` performs no GitHub release request.

- [ ] **Step 3: Add the backend guard**

Define:

```go
const BuildTypeAox = "aox"

var ErrAoxManagedUpdateDisabled = infraerrors.Forbidden(
    "AOX_MANAGED_UPDATE_DISABLED",
    "updates are managed by the Aox image pipeline",
)

func (s *UpdateService) isAoxManagedBuild() bool {
    return strings.EqualFold(strings.TrimSpace(s.buildType), BuildTypeAox)
}
```

At the start of `CheckUpdate`, return:

```go
if s.isAoxManagedBuild() {
    return &UpdateInfo{
        CurrentVersion: s.currentVersion,
        LatestVersion:  s.currentVersion,
        HasUpdate:      false,
        BuildType:      BuildTypeAox,
    }, nil
}
```

At the start of `PerformUpdate`, `Rollback`, `ListRollbackVersions`, and `RollbackToVersion`, return `ErrAoxManagedUpdateDisabled`.
