# Upstream v0.1.183 Catch-up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Merge the exact official Sub2API `v0.1.183` tag into the Aox fork while preserving the fork's payment, managed-release, Go 1.27, and affiliate-rebate behavior.

**Architecture:** Perform one non-squashed merge from the verified annotated upstream tag, then resolve and review every file changed on both sides. Validate database migrations and money paths separately before allowing a fork-only pull request or candidate image.

**Tech Stack:** Git, Go 1.27.0, PostgreSQL migrations, Redis, Vue 3, TypeScript, pnpm 9, Docker Buildx, GitHub Actions.

**Spec:** [GitHub Issue #12](https://github.com/iHuHoo/sub2api/issues/12)

## Global Constraints

- Upstream input is the exact official tag `v0.1.183`, peeled commit `e8cb019fabf8b55199436229044cbf9aa7a82564`.
- The merge base must remain official `v0.1.165`, commit `e9a58c1cb8b5ef626a75c93b4d953fde5e67aa29`.
- Never push to, merge into, or create branches in `Wei-Shaw/sub2api`.
- Preserve WooshPay checkout/webhook behavior, CNY subscription conversion, recharge multiplier precision, USD affiliate rebate basis, subscription daily-limit USD basis, and managed-update prohibition.
- Preserve the fork's exact Go `1.27.0` build and CI requirement unless upstream code is incompatible and the incompatibility is demonstrated by a failing check.
- Do not edit historical payment, rebate, or migration records.
- Do not deploy to production from this branch. A candidate image requires a green PR and explicit human promotion.
