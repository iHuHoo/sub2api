# Clash 订阅操作与启用检查

本功能默认关闭。本 PR 不授权生产迁移、DNS/Nginx 调整或启用。

## 配置与权限

```yaml
clash_subscription:
  enabled: false
  public_base_url: "https://api.aoxtoken.com"
```

启用时必须使用 HTTPS，不接受 userinfo、query、fragment。第一版仅支持根地址，不支持路径前缀；不能用 frontend_url 代替。启用需要单独安排迁移、备份、恢复验证和窗口。

管理员只导出无供应商归属/分配的公共代理；供应商只导出分配给自己的有效代理，不包含自建代理。原有列表仍脱敏，分配代理仍不能修改、删除。普通用户和模型 API key 不能管理订阅。管理接口使用用户 JWT。

每用户一个生命周期记录。创建/重置只展示一次明文链接；关闭弹窗后无法恢复。有效期为 30/90/365 天，默认 90 天。重置后需要在客户端重新导入。

管理员和供应商创建/重置均遵守 `step_up_enabled`（默认关闭）。开启时必须先启用 TOTP，并取得当前会话的短期验证授权；元数据读取和撤销无需 step-up。两种角色均可从「个人资料」进入双重认证设置（`/profile` → `ProfileTotpCard`），供应商的 `/user/totp/*` 已在自助接口允许名单中。启用 step-up 前应先确保全站 TOTP 可用、用户能完成设置。验证通过后须手动重试创建/重置，界面不会自动重放；关闭订阅弹窗会取消待完成的提示。

角色变化、停用和首次软删除自动撤销。**管理员第一版不能直接撤销某个供应商的订阅。供应商链接泄露时，可停用供应商后再启用；停用会撤销，重新启用不会恢复旧链接。** 此操作也影响供应商其他访问能力，应按运维授权执行。供应商需要显式重置才能获得新链接。

撤销只能阻止后续下载。已下载的代理密码无法收回；立即阻断需要另行轮换上游凭据。撤销前已经开始的快照下载可能完成一次。

## 启用前必须取得的证据

以下三项必须同时成立，缺少证据就保持关闭：

1. `api.aoxtoken.com` 权威与客户端递归解析的 A/AAAA（包含 CNAME 链）均是本次批准的源站地址，无遗留 IPv6/CDN 路由。
2. 与核验当时 Cloudflare 官方 IPv4/IPv6 网段逐一对照，所有解析地址均不在其中。保存核验日期、地址和结论。
3. 在 DNS 控制台/API 确认记录为“仅 DNS”/`proxied=false`，保存脱敏证据。

DNS/CDN 改动后必须重新核验；若改成代理，先关闭订阅并处理可能的链接暴露。Host 检查无法删除用户误发到 Cloudflare 域名的边缘日志。

Nginx 必须保留原始 Host，不能把任意来源 Host 重写成允许域名。前端域名同路径拒绝且不跳转。下载应直达固定 `/api/v1/clash/subscription`，不得做带 query 的规范化跳转。

## 日志检查

使用假 token 和假凭据，逐一请求 200/404/405/429/503、尾斜杠和编码路径。检查 api vhost access/error、轮转文件、应用日志、审计及已部署的 APM/错误采集。不得出现 query、完整订阅链接、配置正文、代理密码或 token/hash。

该路径的 access 格式只保留固定路径、状态、耗时，不能使用 `$request`、`$request_uri`、Referer 或任意客户端 header。Nginx error 日志可能附带完整 request；因此该下载 location 应禁用错误日志输出，或采用已验证可去 query 的独立收集链。仅修改 access 格式不够。反向代理产生的错误也要故意触发并检查。生产证据未取得，不得启用。

应用下载处理不记录 body/query；管理审计只记录动作和结果，不记录 grant 响应。全局 OPTIONS 仍返回 204/403 且没有配置内容；其他下载响应清除跨域允许头，包含 private/no-store、no-referrer、nosniff。Redis 故障返回 503，不放行下载。

## 客户端验收

以独立测试配置和假代理验证，不能导入生产链接做日志实验。记录客户端和内核版本。

- HTTP/HTTPS/SOCKS5/SOCKS5h、IPv6、特殊字符凭据和重名节点。
- SOCKS5h 导出为 socks5，假 SOCKS 上游必须收到域名类型目的地址。
- 非空与零节点配置均经 Mihomo `-t`；零节点配置选择 REJECT，无 DIRECT 回退。
- Clash Verge 导入、更新、选择、重置旧链接失败；记录零节点更新时旧节点是否保留，不承诺客户端清除。
- HTTPS 证书验证不得关闭；若失败，不得自动换为 HTTP。
- HTTP/HTTPS 空用户名但有密码的节点会原样导出，但 Mihomo 可能不会发送代理认证，导致连接失败；管理员应补全用户名后再导出。SOCKS 同类配置会跳过并报告 `SOCKS_AUTH_USERNAME_REQUIRED`。

## 回滚与关闭

关闭 `clash_subscription.enabled` 或回滚应用停止未来下载，不恢复旧链接。可以保留订阅表及用户触发器；旧应用更新余额不触发撤销，更新角色/状态仍会撤销。未来删除表须先删除依赖触发器/函数。保留备份直到相应部署复查通过。
