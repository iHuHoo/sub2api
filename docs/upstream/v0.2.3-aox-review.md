## Aox compatibility review

- Aox subscription promo-code migration 231 remains intact; migrations 235 and 236 do not collide with it.
- Promo reservation, consumption, one-use enforcement, discounted totals, refund handling, and final reservation release remain wired and tested.
- WooshPay, payment-currency snapshots, and subscription USD-to-CNY conversion remain present.
- Subscription affiliate rebates still use the discounted order USD `Amount`, not gateway `PayAmount`.
- Go remains pinned to 1.27.0, including native HTTP/2 PING health checks.
- The Aox build type, independent release revision, managed updater, build workflow, and upstream monitor remain intact.
- Moved two English promo table labels from the unrelated redeem-code namespace into the promo-code namespace so the new locale-completeness check covers the Aox UI correctly.
- Updated the new Codex-manifest view test to mock the current auth store and renamed model-allowlist API, preventing a missing-Pinia failure and a swallowed API TypeError.
