## Migrations and rollback

- `238_opencode_go_platform.sql` extends platform constraints while retaining MiniMax.
- `238_purge_unlimited_user_platform_quotas.sql` deletes quota records whose three limits are all NULL. Explicit zero limits remain configured limits.
- The two migrations intentionally share the numeric prefix: the runner sorts and records complete filenames, so both execute independently. Existing fork migration 231 is unchanged.
- Before a later production deployment, back up the database. Reverting code does not restore deleted unlimited-quota counters; restoring those requires a backup. Large quota tables may require a longer migration timeout or staged cleanup.
