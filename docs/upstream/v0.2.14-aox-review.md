## Scope and compatibility

Fresh installations generate a random administrator email when ADMIN_EMAIL is absent, and validate explicit email/password configuration. Existing installations with users/admins are unaffected. Codex configuration adds API-key model discovery support. Frontend dependencies update Vue and source-map-js through the upstream lockfile.

No new database migrations or backend dependency changes in this interval. Existing Aox payment, promo, currency, affiliate and Go 1.27 behavior must be retained. Source sync only: no release tag, image publication, deployment or production configuration changes.
